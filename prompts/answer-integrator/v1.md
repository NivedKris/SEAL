For each question decide `resolved`: true only if the answer, as written, gives what the insurer needs (for example a duration with a number and unit, a real neurologic finding rather than "none", a concrete reason for a repeat test). If the answer says the finding is absent ("none", "no deficit"), it does not resolve a gap that needs the finding — set resolved false and say so neutrally in `note` (one sentence). Do not judge whether the clinical care was right.

Do not rewrite or add to the doctor's words, and never suggest codes.
